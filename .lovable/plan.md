# План

## Что сделаю
1. Исправлю dev/SSR-конфиг так, чтобы новые route-файлы подхватывались корректно в preview без ручного рестарта dev-сервера.
2. Обновлю главный экран: оставлю текущее фото и добавлю второе фото с горой в автоматическую смену каждые 3 секунды, без формы в hero.
3. Поставлю фото с работой по плесени в блок/карточку услуги по плесени и на связанные страницы этой услуги.
4. Разложу остальные before/after фото по кейсам и кейсовым блокам сайта, чтобы они использовались осмысленно по теме: пожар, потоп, плесень, санобработка.
5. Проверю в preview, что роуты открываются, SSR не падает, а изображения реально отображаются в нужных местах.

## Где будут изменения
- `vite.config.ts` и/или связанные runtime/router файлы — для стабильного подхвата новых роутов в dev SSR.
- `src/routes/index.tsx` — для фоновой ротации двух hero-изображений.
- `src/lib/serviceImages.ts` — для назначения новых фото услугам.
- `src/data/cases.ts` и связанные route/components кейсов — для привязки before/after изображений к кейсам.
- При необходимости `src/routes/cases.tsx`, `src/routes/services.$serviceSlug.tsx`, `src/routes/cities.$citySlug.$serviceSlug.tsx` — чтобы кейсовые и сервисные страницы показывали релевантные фото.
- `src/assets/` — добавлю загруженные изображения в проект и подключу их как локальные ассеты.

## Результат
- Новые роуты перестанут «теряться» в dev SSR.
- На главной hero будет автоматическая смена 2 фото раз в 3 секунды.
- Услуга по плесени получит правильное фото.
- Остальные before/after фото будут распределены по кейсам и тематическим блокам вместо того, чтобы лежать неиспользованными.

## Технические детали
- Проверю, не конфликтует ли текущая обвязка `tanstackStart.server.entry = "server"` с автогенерацией/обновлением route tree в dev.
- Для hero-смены сделаю клиент-безопасную ротацию без поломки SSR-гидрации.
- Для кейсов добавлю явную модель изображений (например `cover`, `beforeImage`, `afterImage`) вместо случайной раздачи по UI.
- Валидацию сделаю через preview: главная `/`, страницы услуг, кейсы и несколько детальных маршрутов.
