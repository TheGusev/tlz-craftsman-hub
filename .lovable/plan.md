## Раскрывающееся меню связи в правом нижнем углу

Переделать компонент `src/components/site/UrgentCTA.tsx`: вместо постоянно видимой колонки из 3 кнопок — одна круглая кнопка с иконкой телефона, по клику раскрывается список с вариантами связи (Позвонить, MAX, Telegram), повторный клик/крестик — сворачивает.

### Поведение

- По умолчанию видна **только круглая кнопка с иконкой телефона** (зелёная, фирменный акцент).
- При нажатии:
  - кнопка превращается в крестик (×);
  - над ней снизу вверх с анимацией появляются 3 пилюли:
    1. **Позвонить** — зелёная, иконка трубки → `tel:+78005551234`
    2. **MAX** — голубая, иконка пользователя → ссылка на MAX-мессенджер
    3. **Telegram** — голубая, иконка самолётика → `https://t.me/...`
- Клик вне меню или по крестику — сворачивает список.
- Esc — закрывает.

### Технические детали

- `useState` для `isOpen`.
- Иконки из `lucide-react`: `Phone`, `X`, `Send` (Telegram), `User` (MAX).
- Анимация появления — Tailwind `transition` + `translate-y` + `opacity`, с задержкой по индексу для каскадного эффекта.
- Пилюли: `rounded-full`, текст слева + круглая иконка справа (как на референсе пользователя).
- Главная кнопка: `h-14 w-14 rounded-full`, тень.
- Закрытие при клике вне — через `useEffect` + `mousedown` listener на `document`.
- Сохранить `z-30`, позицию `fixed bottom-4 right-4 md:bottom-6 md:right-6`.
- Вопрос: ссылку на Telegram и MAX оставляю текущие плейсхолдеры (`https://t.me/...`, MAX — `https://max.ru/...`); если есть конкретные — поменяю после реализации.

### Что НЕ меняется

- Никаких других файлов.
- Логика контактных номеров и WhatsApp-сценария остаётся (WhatsApp убираем из этого виджета, так как пользователь явно перечислил только Позвонить / MAX / Telegram — подтвердить, если нужно вернуть).
