## Цель

1. Убрать из видимого UI все блоки кейсов, пока они сняты в Краснодаре/Сочи/Ростове/Симферополе — на страницах, где остались только Москва и МО.
2. Прогнать полную сборку (`build:prod` с prerender и SEO-проверками), найти и устранить причину красного CI после вчерашних правок.

## Часть 1. Скрытие кейсов

Ввести один флаг видимости кейсов (например `CASES_PUBLIC = false` в `src/data/cases.ts` или `src/lib/site.ts`), чтобы позже включить обратно одной строкой после переписывания под столичный регион.

Скрыть блоки в:
- `src/routes/index.tsx` — секция «Реальные кейсы» (6 карточек) и ссылка «Все кейсы →»
- `src/routes/cities.$citySlug.tsx` — блок кейсов города (у Москвы/МО кейсов нет, у скрытых городов остаётся текст)
- `src/routes/services.$serviceSlug.tsx` — блок кейсов по услуге
- `src/components/site/Header.tsx` / `src/components/site/Footer.tsx` — ссылки «Кейсы» в меню и футере

Страницы `/cases` и `/cases/$slug` остаются рабочими и в sitemap (не теряем проиндексированный контент), просто на них нет ссылок из UI. Если вы предпочитаете полностью убрать их из индекса — скажите, поставлю `noindex` и уберу из sitemap.

## Часть 2. Починка сборки

Диагноз пока не подтверждён: локальный typecheck чистый, а лог CI недоступен из скринов (виден только красный крестик). Поэтому первым шагом — воспроизведение:

1. Запустить `npm run build:prod` целиком (vite build → generate-seo → prerender → `--verify` → `--verify-jsonld`) и прочитать вывод полностью.
2. Наиболее вероятные места отказа после вчерашних правок: prerender падает на роутах скрытых городов (`route rendered ErrorComponent`) из-за `citiesForDropdownWith` / пустого списка городов в формах, либо `--verify` ругается на изменившиеся тексты/мету на `/cities`.
3. Исправить конкретную найденную ошибку, повторить прогон до зелёного.
4. Дополнительно прогнать `scripts/audit-geo.ts` и убедиться, что в sitemap по-прежнему 134 URL.

## Технические детали

- Флаг видимости — обычная константа в данных, никаких изменений в роутинге и генерации sitemap.
- В `route-config.ts` маршруты кейсов не трогаем.
- Проверка успешности: `npm run build:prod` завершается с кодом 0 и без строк `Error` в выводе.
