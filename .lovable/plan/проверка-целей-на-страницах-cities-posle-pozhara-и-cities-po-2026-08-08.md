# Проверка целей на страницах /cities/*/posle-pozhara и /cities/*/posle-potopa

## Что уже проверено в коде

- `trackGoal` дублирует цель с суффиксом услуги только если в параметрах передан `service` (слаг). Логика корректна.
- Телефон и WhatsApp в hero страницы город×услуга передают `service: service.slug` — цели `lead_phone_click_posle_potopa` / `lead_whatsapp_click_posle_potopa` отправляются.
- Шапка, подвал и плавающий виджет берут услугу из URL — суффикс проставляется.

## Найденные несоответствия

1. **Форма заявки в сайдбаре не даёт суффикс.** На странице город×услуга форма подключена без параметра услуги (передаётся только человекочитаемое название для подстановки в поле). В цель уходит `service: null`, поэтому `lead_form_submit_posle_pozhara` / `_posle_potopa` **не отправляется** — только базовый `lead_form_submit`.
2. **То же на посадочных /lp/**: форма подключена без параметра услуги, суффикс не уходит.
3. **`lp_quiz_complete_posle_*` на /cities/ вообще не может отправиться** — квиз расчёта стоимости на страницах город×услуга не размещён, он есть только на /lp/. Там суффикс проставляется корректно.

## Что сделаю

1. Передать слаг услуги в форму заявки на страницах город×услуга и на /lp/, чтобы цель `lead_form_submit` уходила вместе с `lead_form_submit_<услуга>`.
2. Добавить квиз расчёта на страницы город×услуга (тот же компонент и стиль, что на /lp/), чтобы работала цель `lp_quiz_complete_<услуга>`. Если квиз на этих страницах не нужен — этот пункт убираем, и цель `lp_quiz_complete_posle_*` остаётся только на /lp/.
3. Прогнать реальную проверку в браузере на `/cities/moskva/posle-pozhara` и `/cities/moskva/posle-potopa` (плюс МО): клик по телефону, WhatsApp, Telegram/MAX, отправка формы, прохождение квиза — и зафиксировать содержимое `window.dataLayer` с полным списком отправленных целей.
4. Выдать отчёт: цель → отправляется/нет → параметры (`city`, `service`, `source`).

## Технические детали

- `src/routes/cities.$citySlug.$serviceSlug.tsx`, `src/routes/lp.$citySlug.$serviceSlug.tsx`: добавить проп `service={service.slug}` в `LeadForm`.
- При добавлении квиза — `PriceQuiz` с `serviceSlug`/`citySlug` из loader-данных.
- Проверка — Playwright-скрипт против локального dev-сервера, чтение `window.dataLayer` после каждого действия.
